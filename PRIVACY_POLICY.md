# Privacy Policy for UtilityHub

**Last Updated:** October 2024

**UtilityHub** is built with user privacy as a core principle. This policy describes how data is handled by the application.

---

## 1. On-Device Local Data Processing
All photos, videos, audio tracks, PDFs, documents, archives, and text files selected by the user are processed **100% locally on your device**. UtilityHub does not upload, store, or transmit your files to any remote server or third-party service.

## 2. Authentication & Account Security
User authentication is handled securely via **Firebase Authentication** (Google Cloud). When registering or logging in:
- Your email address and password credentials are handled by Firebase Authentication.
- UtilityHub never sees, stores, or logs your password.
- Verification and password reset emails are sent directly by Firebase Authentication.

## 3. Local Application Data
UtilityHub stores the following information locally on your device:
- Theme and favorite tool preferences (via DataStore).
- Notes and scratchpad entries (stored in local application database).
- Completed tool history logs (tool names and timestamps only; file names and contents are never logged).
- Temporary cache files created during processing, which can be cleared anytime in Settings.

## 4. Permissions
UtilityHub requests only necessary Android permissions:
- **Internet Permission**: Required solely for Firebase Authentication.
- **Media & Storage Access**: Used when selecting files and saving generated outputs.
- **Notifications**: Used to notify you when file processing operations complete.

## 5. Analytics & Tracking
UtilityHub contains **no analytics tracking**, no crash report harvesting, and no advertising SDKs.

## 6. Contact & Data Deletion
You can delete your account and clear all local data directly within the application under **Settings → Account** or by uninstalling the app.
